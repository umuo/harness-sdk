# 中文发布说明

先阅读 `references/template.md`，然后严格按照模板组织发布说明。

写作要求：

1. 先说明用户能够获得什么，而不是先罗列内部实现。
2. 明确兼容性和升级影响，不能把推测写成事实。
3. 每个能力至少给出一个具体使用场景。
4. 使用简洁中文，不使用营销式夸张表达。
5. 如果输入没有提供风险或限制，明确写“未提供”，不要自行编造。
